# PARI result updater

Загрузчик общедоступных результатов PARI Universe (OpenDota league 20395) для закрытого Dota Team Tracker.

В репозитории только код и расписание. Здесь нет сайта, личного журнала, паролей пользователей и исходных ответов API. Запуски используют стандартный Linux runner GitHub Actions, бесплатный для публичных репозиториев. Более крупные платные runner'ы не используются.

## Как работает

- Примерно раз в 5 минут получает список завершённых карт и до пяти подробных ответов. Расписание GitHub может задерживаться.
- Отправляет только необходимые поля в закрытый приёмник Cloudflare; ключ хранится в Actions Secrets `PARI_INGEST_TOKEN`.
- Приёмник проверяет турнир, команды и результаты, сохраняет предыдущие подробности, если новый ответ неполный.
- Отсутствующие пики, баны, убийства и ники не заменяются нулями.
- Учитывает HTTP 429, Retry-After и суточную квоту. При ошибке сохраняются прежние результаты и честная дата обновления.
- После 5 ноября 2026 сбор прекращается. Затем можно отключить workflow в Actions.

Проверка: `node --test test.mjs`. Ручной запуск: Actions → Update PARI results → Run workflow.

Для настройки нужны secret `PARI_INGEST_TOKEN` и variable `PARI_SITE_URL`. Ключ разрешает читать и обновлять только общедоступные результаты PARI, не журнал и не сайт. Административный токен Cloudflare в GitHub не передаётся.

Это периодическое обновление, не live API: OpenDota также может публиковать подробности с задержкой или ограничивать запросы. Первый успешный запуск Actions нужно проверить отдельно. Сохранённые анализы сопоставляются с картами по обеим пятёркам героев при следующем открытии сайта. Сами анализы хранятся в Cloudflare отдельно для каждого логина.
